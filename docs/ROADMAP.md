# 로드맵

v0.3에서 Phase 0~5의 기능과 1차 감사(8개 관점, 109건 지적)에서 확인된 결함·공백을 모두 반영했습니다. 아래는 각 단계에서 무엇이 실제 동작이고 무엇이 시뮬레이션인지, 그리고 실제 현장 적용을 위해 남은 일입니다.

| Phase | 상태 | 실제 동작 | 시뮬레이션/대체 |
|---|---|---|---|
| 0 합성 데이터 MVP | ✅ | 비전·판정·SPC·리포트 | 이미지가 합성 |
| 1 검사 신뢰성 | ✅ | 특성별 가드밴드(Gage 기반), 등급, ERROR 판정, ANOVA Gage R&R(균형 검증) | 재고정 조건을 렌더링으로 모사 |
| 2 실제 이미지 | ✅ 도구 | import(매니페스트)/16-bit/레터박스/교정(포켓 불필요)/MVTec 평가, 명암 극성·크기·조명 기울기 무관 | 실제 사진 검증은 사용자가 수행 |
| 3 딥러닝 | ✅ (CNN 없이) | PatchCore 방식 메모리뱅크, 코어셋, 중복 제거·임계값 하한, 하이브리드 규칙 | 임베딩이 수작업 특징 (CNN 교체 지점 명시) |
| 4 스마트 팩토리 | ✅ | SQLite(WAL)·원자적 체인·앵커, 처분/재검사/Lot 마감, 관리한계 동결, 교정 기록, 알람 확인, REST(인증), Streamlit, MQTT | 카메라·PLC 대신 시뮬레이터 |
| 5 방산 특화 | ✅ | ISO 2859-1(표 구조 검증), c=0 정확 초기하, 치명결함 Lot 규칙, 검사 기준서(사유 코드·관리한계), 오프라인 번들·잠금 파일 | MIL-STD-1916 고유 표 미구현 |

## v0.3에서 고친 주요 결함 (감사 결과)

- 비전: 큰 프레임의 작은 부품에서 NaN 기하·엉뚱한 외경 → Otsu·검증·`VisionError`; 경계에 걸린 부품이 PASS → `part_touches_border`; 반전 명암·RGB·16-bit·float 입력 크래시/오판 → `to_gray8`; 조명 기울기로 동심도 ±0.04 mm 치우침 → 섹터별 기준레벨; 밝은 점이 찍힘으로 불합격 → 극성 구분; 결함 길이 20~50 % 과대 → 주축 extent(±15 %).
- 통계: ISO 2859-1 AQL 0.065/0.10/0.15 열이 한 칸 느슨, 위쪽 화살표 미처리 → 표 구조 인코딩 + 전 셀 생산자 위험 테스트; c=0 계획의 부동소수 올림 오류; Western Electric 규칙 2·3 시작 구간 누락; 불균형 Gage 데이터로 엉뚱한 %GRR → 검증.
- 추적성: 동시 쓰기 시 체인 분기, NaN 저장으로 체인 영구 훼손, 최신 행 삭제 미탐지 → 원자적 트랜잭션·정규화·앵커; API 공유 커넥션 경쟁, 인증·업로드 제한 부재, 비전 오류가 NG로 집계.
- 도메인 공백: 처분/재검사 워크플로, Lot 마감 기록, 관리한계 동결(재시작 시 재기준선 방지), 교정 기록, 알람 확인, 교대 리포트, 작업자·영상 증거, Lot↔규격 바인딩, 한글 사유 카탈로그.

## 현장 적용을 위한 다음 작업

### 1. 실제 부품으로 검증 (가장 먼저)
- 저가 세팅: 웹캠/산업용 카메라 + 링 조명 + 와셔·너트 등 원형 금속 부품
- `qinspect import` → `calibrate`(기준 디스크) → `inspect` → 유출/과검 확인 → `gage`로 가드밴드 재산정
- 공개 데이터셋: MVTec AD `metal_nut`/`screw` (비상업 라이선스), Kaggle casting, NEU-DET → `anomaly-eval`
- 예상 조정: `detect_defects` 의 `k_sigma`/`min_abs`, 이상탐지 `threshold_sigma`, 등급 길이 기준

### 2. CNN 임베딩
- `anomaly.patch_features` 를 ResNet/WideResNet 중간층(anomalib PatchCore)으로 교체
- 비교표: 수작업 특징 vs CNN — AUROC, 양품 오탐, 추론 시간, 모델 크기(폐쇄망 반입 용이성)

### 3. 설비 연동 실물
- MQTT → OPC UA 서버(`asyncua`)로 PLC 태그 쓰기, 검사 트리거 수신
- MES 연동: Lot 생성/종료 API 연계, 작업지시 번호를 `lots` 테이블에 연결
- 다중 스테이션: PostgreSQL 백엔드, 스테이션별 관리도

### 4. 품질 시스템 문서화
- MIL-STD-1916 검증수준(VL)별 표 입력 및 테스트
- AS9102 초도품검사(FAI) 양식 자동 채움 (`specdoc` 확장)
- 변경 관리: 규격/모델 해시 변경 승인 테이블, 전자 서명

### 5. 보안·운영
- 앵커 머리 해시의 외부 타임스탬프/WORM 보관 자동화
- API 역할별 권한(검사원/품질관리자/감사), mTLS
- 보존 주기·아카이브(기간별 내보내기 + 앵커), 백업 검증 자동화
