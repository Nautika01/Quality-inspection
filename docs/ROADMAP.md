# 로드맵 (1인 진행 기준)

각 단계는 **혼자서 1~3주** 안에 끝낼 수 있는 크기로 나눴습니다. 단계마다 "완료 기준"을 지키면 포트폴리오에서 바로 보여줄 수 있는 결과물이 남습니다.

## Phase 0 — 합성 데이터 MVP ✅ (현재)
- 합성 이미지 + 정답, 전통 비전(치수/결함), 판정, SPC, 리포트
- 완료 기준: `qinspect demo` 한 줄로 결과 재현, 테스트 통과

## Phase 1 — 검사 신뢰성 다듬기
- **가드밴드(guard band)**: 측정 불확도만큼 공차를 안쪽으로 좁혀 판정 → 경계 부품 유출 방지
  (데모에서 실제값 12.1013 mm / USL 12.10 mm 부품이 측정값 12.0955 mm로 PASS 된 사례가 바로 이것)
- **MSA / Gage R&R**: 같은 부품을 조명·위치를 바꿔 반복 촬영 → 반복성·재현성, %GRR 계산
- 결함 크기 기준 판정(예: 스크래치 길이 ≥ 0.5 mm만 불량), 치명/중/경결함 등급
- 완료 기준: %GRR 리포트, 가드밴드 적용 전후 유출/과검 비교표

## Phase 2 — 실제 이미지로 확장
- 공개 산업 데이터셋으로 검증 (라이선스 확인 필수)
  - MVTec AD (`metal_nut`, `screw` 등 — 비상업 라이선스)
  - Kaggle casting product (주조품 상면)
  - NEU-DET (강판 표면 결함)
- 저가 하드웨어로 직접 촬영: 웹캠/산업용 카메라 + 링 조명 + 와셔·너트·볼트 등 금속 부품
- 완료 기준: 실제 이미지에서 치수 측정 오차와 결함 검출률 리포트

## Phase 3 — 딥러닝 검사
- 정상품만으로 학습하는 **이상 탐지**: PatchCore / PaDiM (anomalib) — 불량 샘플이 적은 방산 현장에 적합
- 결함 위치·유형 검출: YOLO 계열
- 전통 비전(치수)과 딥러닝(외관)을 결합한 하이브리드 판정, Grad-CAM 등으로 판정 근거 시각화
- 완료 기준: 전통 비전 vs 딥러닝 비교표 (정확도, 유출률, 추론 시간)

## Phase 4 — 스마트 팩토리 연동
- 검사 결과 DB 저장 (SQLite → PostgreSQL), Lot/Serial 기반 추적성
- 실시간 대시보드: Streamlit 또는 Grafana (수율, 관리도, NG 사유 파레토)
- 설비 연동 시뮬레이션: MQTT / OPC UA로 PLC·MES에 판정 결과 송신, 관리도 이상 시 알람
- REST API (FastAPI) + Docker
- 완료 기준: 가상 라인에서 "촬영 → 판정 → DB → 대시보드 → 알람" 데모 영상

## Phase 5 — 방산 특화 요소
- **폐쇄망(온프레미스) 배포**: 외부 네트워크 없이 동작, 모델·의존성 오프라인 설치
- **감사 추적(audit trail)**: 검사 기록 위·변조 방지(해시 체인), 검사 프로그램·모델 버전 기록
- 품질 표준 반영
  - 샘플링 검사: MIL-STD-1916, KS Q ISO 2859
  - 항공·방산 품질경영: AS9100, 초도품검사(FAI) AS9102
  - 국방규격(KDS) 형식의 검사 기준서 작성
- 완료 기준: 표준 기반 검사 기준서 + 감사 로그가 남는 배포 패키지

## 주의 사항
- 실제 방산업체 도면·영상·규격치는 보안 대상일 수 있으니 저장소에 올리지 마세요. 공개 데이터와 가상 규격만 사용합니다.
