## 1. 적용 범위
자동 비전 검사 셀에서 수행하는 전수 검사(치수·외관)와 Lot 판정(샘플링)에 적용한다.

## 2. 치수 검사

| 특성 | 공칭 (mm) | 도면 공차 (mm) | 판정 한계 (가드밴드 적용) | 측정 방법 |
|---|---|---|---|---|
| 외경 | 12.000 | 11.900 ~ 12.100 | 11.906 ~ 12.094 | 비전 서브픽셀 측정 |
| 프라이머 포켓 직경 | 5.000 | 4.920 ~ 5.080 | 4.926 ~ 5.074 | 비전 서브픽셀 측정 |
| 포켓 동심도 | 0 | ≤ 0.100 | ≤ 0.094 | 외경·포켓 중심 거리 |

* 가드밴드 0.006 mm 는 측정 불확도를 반영해 공차 안쪽으로 판정 한계를 좁힌 값이다 (ISO 14253-1 판정 규칙).
* 픽셀 스케일 16.0 px/mm, 영상 크기 256 px. 교정은 기준 게이지로 교대 시작 시 실시한다.

## 3. 외관 검사

| 등급 | 기준 | 처리 |
|---|---|---|
| 치명 (critical) | 길이 ≥ 1.0 mm 또는 유형 crack | 불합격, 즉시 알람 |
| 중 (major) | 길이 ≥ 0.5 mm | 불합격 |
| 경 (minor) | 길이 < 0.5 mm | 합격, 기록 유지 |

* 검출 대상: 스크래치, 찍힘(dent). 최소 검출 면적 12 px.
* 이상탐지 모델 사용 시 점수가 학습 임계값을 넘으면 사유 `anomaly_score`로 불합격 처리한다.

## 4. 측정 시스템

| 특성 | %GRR (TV) | %GRR (공차) | ndc | 판정 |
|---|---|---|---|---|
| outer diameter | 4.5 % | 8.6 % | 31 | acceptable |
| pocket diameter | 8.0 % | 18.8 % | 17 | marginal |

* AIAG MSA 기준: 10 % 미만 양호, 10~30 % 조건부, 30 % 초과 부적합.

## 5. Lot 판정 (샘플링)

* 전수 비전 검사 결과와 별도로, 출하 Lot 은 KS Q ISO 2859-1 single/normal, 검사수준 II, AQL 1.0 % 로 판정한다.
* Lot 크기 1000 → 코드문자 J, 샘플 n = 80, Ac = 2, Re = 3
* 샘플에서 치명 결함 1건 이상 발견 시 AQL 과 무관하게 Lot 불합격 (c = 0 규칙).

## 6. 기록 및 추적성
* 시리얼별 판정, 측정값, 결함 좌표, 프로그램 버전, 규격 해시, 모델 해시를 DB 에 저장한다.
* 검사 기록은 해시 체인으로 연결되어 사후 위·변조 시 `audit/verify` 에서 탐지된다.
* 보존 기간: 계약 요구에 따름 (방산 품질보증 요구사항 참조).

## 7. 공정 관리
* 외경에 대해 X̄-R 관리도(n = 5)를 운용하고 Western Electric 규칙 1~4 위반 시 알람을 발행한다.
* Cpk < 1.33 이면 공정 개선 조치, Cpk < 1.0 이면 전수 선별 및 원인 분석.
